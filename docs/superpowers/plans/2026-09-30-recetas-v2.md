**Goal:** Reemplazar placeholder Recetas por gestión master-detail con costo + alertas.

**Architecture:** Container `RecetasPage.jsx` (lista productos + detalle) + `RecetaPanel.jsx` (tabla + form) + `recetasService.js` (CRUD /api/v1/recipes con fallback). Reuso Card/Badge/Alert/Skeleton/EmptyState/RequirePermiso. Sin backend en este plan (solo frontend, fallback 404).

**Tech Stack:** React 18.3.1, Vite 5.4.11, React Router 6.28, Vitest 2.1.8 + Testing Library, Bootstrap 5.3 + Bootstrap Icons, Supabase JS (JWT Bearer via api.js).

## Global Constraints

- No compartir tablas/lógica POS/Monitoreo — solo contrato REST.
- JWT desde sesión Supabase, userId nunca desde frontend (AGENTS §4.1).
- RBAC: leer `producto.consultar`, mutar `producto.gestionar` con `<RequirePermiso>`.
- Cantidades NUMERIC(14,4), `cantidad_requerida > 0`, UNIQUE(producto,insumo) → 409.
- No subir `.env`, no `passwordHash`, no service-role en frontend.
- Frontend no muta stock; solo lectura para porciones/costo.
- Seguir patrón `api.get/post/patch/remove` de `src/services/api.js`.
- No crear `ProductoPOS/RecetaPOS`; usar `receta_insumo(producto_id, insumo_id, cantidad_requerida)`.

```js
// src/utils/receta.js
export function validarCantidad(v) {
  const n = Number(v);
  if (!Number.isFinite(n) || n <= 0) return 'Cantidad debe ser > 0';
  if (n > 999999) return 'Cantidad excesiva';
  return null;
}
export function calcularPorciones(lineas = []) {
  if (!lineas.length) return 0;
  let min = Infinity;
  for (const l of lineas) {
    const stock = Number(l.stock ?? 0);
    const req = Number(l.cantidad_requerida ?? 0);
    if (!req || req <= 0) return 0;
    min = Math.min(min, Math.floor(stock / req));
  }
  return min === Infinity ? 0 : Math.max(0, min);
}
export function calcularCosto(lineas = []) {
  return lineas.reduce((acc, l) => acc + Number(l.cantidad_requerida || 0) * Number(l.costo_unitario || 0), 0);
}
```
